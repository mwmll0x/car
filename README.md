# Машинка на CSS

Машинка нарисована одним элементом `<div class="car">`: кузов — сам `div`, крыша с окнами — `::before`, колёса — `::after`.

- Ширина машинки — 200px.
- При загрузке страницы она выезжает с левого края и останавливается за 50px до правого края (`@keyframes`).
- Пейзаж (небо, трава, дорога, солнце, дерево) сделан фоном и псевдоэлементами `body`, без дополнительных тегов.
